# 日常任务 ADB 自动化说明

## 运行

```bash
C:\Users\123\.conda\envs\Reas\python.exe -I E:\Reverse\auto_script\daily_adb.py --list
C:\Users\123\.conda\envs\Reas\python.exe -I E:\Reverse\auto_script\daily_adb.py --dry-run
C:\Users\123\.conda\envs\Reas\python.exe -I E:\Reverse\auto_script\daily_adb.py
```

常用参数：

- `--only summon,tower,legendary`：只跑指定任务
- `--start tower`：从某个任务开始
- `--dry-run`：只打印计划，不点击

- MuMu Player 12，ADB：`127.0.0.1:16384`
